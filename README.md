# 奇德新材官网改版原型（静态演示站）

广东奇德新材料股份有限公司（300995.SZ）官网改版的现代化静态原型，供设计与开发参考。

## 在线预览

部署后访问：`https://<你的用户名>.github.io/qide-website/`

## 页面结构

| 页面 | 文件 |
|---|---|
| 首页 | `index.html` |
| 关于奇德 | `about.html` |
| 产品中心 | `product.html` |
| 产品详情 | `product-detail.html` |
| 解决方案 | `solutions.html` |
| 应用领域 | `applications.html` |
| 投资者关系 | `ir.html` |
| 联系我们 | `contact.html` |

## 技术说明

- 纯静态 HTML / CSS / JavaScript，零依赖，离线可预览；
- 配色、字号、间距等设计变量集中在 `css/style.css` 的 `:root` 中，改一处全站生效；
- 内容已尽量使用公开真实数据（公司简介、财务数据、认证、客户等）。

> 本仓库为设计原型，仅作展示参考，非官方正式网站。
